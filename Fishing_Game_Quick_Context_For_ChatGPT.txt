Current project context for ChatGPT:
I am building a UE5 fishing game. The player character is BP_Fisherman. The shop widget is WBP_ShopMenu, not WBP_FishMerchantMenu. Inventory uses BP_InventoryComponent with a permanent fixed-slot Items array of ST_ItemData. ST_ItemData fields are HasItem, ItemName, Quantity, ItemIcon, SellValue. Empty slots use HasItem=false, Quantity=0, SellValue=0. Inventory does not use Remove Index for sold items; RemoveItemAtIndex clears the slot with an empty ST_ItemData using Set Array Elem. Inventory UI is WBP_Inventory and WBP_InventorySlot. WBP_InventorySlot receives ItemData, HasItem, DisplayName, DisplayQuantity, DisplayIcon, SlotIndex, and OwningInventoryWidget. Drag/drop uses BP_InventoryDragOperation and WBP_DragItemVisual. MoveOrSwapItem(SourceIndex, TargetIndex) lives in BP_InventoryComponent and moves to empty slots or swaps occupied slots. WBP_ShopMenu has Sell and Buy tabs. The sell tab uses WBP_MerchantSellSlot and fixed sell slots matching inventory indexes. Scales is an integer on BP_Fisherman. Future systems include buy menu items, Fishing Passes, tutorial bait crate quest, and a cooler that starts with 10 extra slots and upgrades by +5 to a maximum of 25 extra slots.
